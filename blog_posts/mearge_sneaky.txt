Fundementally merge sort is a depth first algorithm, where you recurssivly split up an array until you have a bunch of sub arrays with only one element in them and
then you compare the sub arrays and push to a stack(im just calling it a stack for my self its not actually a stack you just push to the end).

ok so our merge does this

let mut i = 0;
let mut j = 0;

let mut merged = Vec::new(); //if you dont know rust this is just how you make a vector mut (very simplified) just means that you can change its value

while i < left.len() && j < right.len() {
    if left[i] < right[j]{
        merged.push(left[i]);
        i += 1;
    } else {
        merged.push(right[j])
        j += 1;
    }
}

ok so lets just focus on this while loop right now, lets say we have two arrays we want to merge and the values are [0, 2] and [1, 2]
all the merge actually does is put the smaller number in then increments the pointer. Looking at merge after each loop it goes

compare 0 and 1
0 is smaller so add 0 to merged
merged[0]
increment i by 1

now we are comparing 2 and 1
1 is smaller so add 1 to merged
merged[0, 1]
increment j by 1

ect ect.

BUT thats the beauty of the merge sort. The sub arrays are already sorted from the smaller parts that the came from.
